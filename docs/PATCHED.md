# Patched bindings

The bindings are generated by runic (Amber's fork, branch `amber-patched`) from the C headers.
Regenerating overwrites hand fixes, so each is also pinned by a typed variable in the
package's `patched.odin`: a regeneration that drops a patch fails to compile there instead
of misbehaving at run time.

To regenerate, run `make generate`, re-apply every row below, and build the package.

Every rule is a `sed` expression in `scripts/postprocess.sh`, run by `make generate` after
runic, so a regeneration reproduces them. `spelling/patched.odin` pins each one.

| Rule | Why |
|---|---|
| `^glib.char` becomes `cstring` | runic 0.8 leaves `gchar *` as a pointer to a char |
| `typedef struct _SpellingFoo SpellingFoo` alias lines are deleted | runic emits both names; the `_` struct is kept and renamed |
| `Spelling` prefix is trimmed from every type name (`SpellingChecker` becomes `Checker`) | `trim_prefix` in `rune.yml` does not reach the typedef aliases |
| `gsv.Buffer` becomes `gsv.SourceBuffer` | odin-gtksourceview keeps the `Source` word of `GtkSourceBuffer` |
| `MAJOR_VERSION`, `MINOR_VERSION`, `MICRO_VERSION` lose their backticks and become numbers | the version test compares them with the README |

libspelling's headers need no `[^]T` correction and take no `va_list`: the generated `spelling.odin`
has no `[^]` parameter and no `#c_vararg` procedure. `scripts/check-generated.sh` keeps it that way
(`make lint`). `spelling/rune.yml` sets `detect.parameters: declared` with an empty `arrays:`,
so every parameter is a single object by construction.
